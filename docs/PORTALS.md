# Portal & Export Documentation

## Faculty Portal

The Faculty Portal displays personal lecture blocks and a weekly teaching-hours counter. Faculty members can view their scheduled lectures and track their weekly workload.

## Student Portal

The Student Portal displays a live "Happening Now" class banner to highlight an ongoing class. It also provides a one-click printable timetable so students can print their schedules easily.

## PDF Timetable Export

The timetable export utility allows users to export their timetable as a PDF. Print styles help format the timetable clearly for printing and displaying on college noticeboards.

## Key Features

- Faculty lecture schedule and weekly workload counter.
- Student live class banner.
- One-click printable timetable.
- PDF timetable export.
- Print-friendly layout for noticeboards.
